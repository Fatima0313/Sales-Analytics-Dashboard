# Sales Analytics Dashboard

## Project Overview

This project analyzes product sales performance using Excel and Power BI.

The objective was to transform raw sales data into an interactive dashboard and investigate changes in sales performance across time, products, regions, orders, quantity, pricing, discounts, and returns.

## Business Questions

The analysis focuses on questions such as:

- How are total sales changing over time?
- Which products generate the highest and lowest sales?
- Which regions contribute the most sales?
- Which products and regions show declining performance?
- How do order volume and quantity affect sales?
- What patterns can be observed in discounts and returns?
- Which periods require further business investigation?

## Tools Used

- Microsoft Excel
- Microsoft Power BI
- DAX
- Data Cleaning
- Exploratory Data Analysis (EDA)

## Data Preparation

The dataset was prepared in Excel before being imported into Power BI.

Main preparation steps included:

- Checking data types and formats
- Checking for duplicate records
- Handling missing values
- Standardizing categorical values
- Converting numerical fields into appropriate formats
- Formatting dates
- Validating sales-related values
- Performing exploratory analysis using Pivot Tables

## Dashboard

The Power BI dashboard contains key performance indicators and visualizations for:

- Total Sales

- Sales trends over time
- Product performance
- Regional performance
- Discount patterns
- Return analysis

## Sales Decline Analysis

A separate analysis page was created to investigate periods of declining sales.

August 2024 was identified as a significant decline period compared with July 2024.

The investigation compared:

- Product-level sales
- Order volume
- Quantity sold
- Unit price
- Discount patterns

The analysis showed that different products experienced different changes in sales, orders, and quantity. Printer also showed an interesting pattern where order volume and quantity increased substantially, demonstrating that order count alone does not explain sales performance.

The available dataset was used to identify patterns and potential areas for investigation. However, the exact business cause of the sales decline cannot be confirmed without additional information such as inventory, promotion, pricing strategy, or external market data.

## Key Insights

- Sales performance varied considerably across products and regions.
- August 2024 showed a notable decline compared with the previous month.
- Laptop and Tablet experienced noticeable decreases in orders and quantity.
- Product performance did not move uniformly across the period.
- Printer showed increased orders and quantity, highlighting the importance of analyzing multiple metrics together.
- Further investigation would be required to determine the exact business causes behind the sales decline.
